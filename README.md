# Task Manager Simple

**Team:** DevOps Team (Manar)
**Project:** Simple Task Manager with Notification System

## Project Description
A simple task manager application that shows notifications when tasks are marked as complete. This project focuses on Git collaboration and version control practices.

## Features
- Complete Task button
- Notification alerts
- Clean UI design
- Git branching workflow

## How to Run
1. Open `index.html` in any browser
2. Click "Complete Task" button
3. See notification message
